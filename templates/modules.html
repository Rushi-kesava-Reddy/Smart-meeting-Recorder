Detailed specifications and real-time statuses of all six interconnected processing engines.

Module 1

Audio Recording & Visualization

recorder.py

Captures voice audio using HTML5 Web Audio API in the browser or hardware sound devices. Provides real-time frequency waveform animation and exports standardized WAV audio files to meetings/meeting.wav.

Primary Technology Web Audio API / MediaRecorder
Output Artifact meetings/meeting.wav

Module 2

Multilingual Speech-to-Text

speech_to_text.py

Executes OpenAI Whisper deep acoustic models via Groq API. Automatically detects spoken languages (Telugu, Hindi, Tamil, Kannada, Malayalam, Bengali, English, etc.) with high accuracy and preserves native script in meetings/transcript.txt.

Primary Technology Groq Whisper (whisper-large-v3)
Output Artifact meetings/transcript.txt

Module 3

Context-Aware AI Translation

translator.py

Translates complete meeting transcripts between Indian regional languages and English or global languages while retaining technical terms, speaker names, and context. Output is saved to meetings/translated_transcript.txt.

Primary Technology Groq LLM (openai/gpt-oss-20b)
Output Artifact meetings/translated_transcript.txt
Live Status Checking...
Open Translator
Module 4

Summarization & Action Extraction

summarizer.py / action_items.py

Distills meeting transcripts into 7 executive sections and structured JSON tables covering Tasks, Responsible Assignees, Deadlines, and Priority Levels in the chosen language. Saved to meetings/summary.txt.

Primary Technology Generative AI Transformers
Output Artifact meetings/summary.txt
Live Status Checking...
Open Summarizer
Module 5

Email Drafting & Prioritization

email_drafter.py

Classifies meeting urgency into Priority tiers (Urgent, High, Medium, Low) with rationale and crafts executive follow-up email drafts with action items and dates. Saved to meetings/email_draft.txt.

Primary Technology NLP Priority Classifier & LLM
Output Artifact meetings/email_draft.txt
Live Status Checking...
Open Email Assistant
Module 6

Unicode PDF Report Generator

report_generator.py

Builds structured, print-ready PDF reports with embedded Google Noto fonts supporting Telugu, Hindi, Tamil, Kannada, Bengali, and English without broken character boxes. Output saved as meetings/Meeting_Report.pdf.

Primary Technology ReportLab 5.0 + Google Noto TTF
