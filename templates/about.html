Project Title

Smart Meeting Recorder using Generative AI

Developer Name

Senior Full Stack Developer (Final Year Project)

Project Objective

Develop a modern, web-based intelligence system that records meeting conversations, automatically transcribes speech into text using deep learning, generates executive summaries via generative AI models, and compiles structured downloadable PDF report documents.

Technologies Used

Frontend Stack

HTML5 CSS3 (Vanilla) JavaScript (ES6+) Web Audio API

Backend Framework

Python 3.x Flask Web Server

AI & Machine Learning Libraries

sounddevice scipy OpenAI Whisper Hugging Face Transformers ReportLab

Interconnected Modules Architecture

01

Module 1: Audio Recording

Captures real-time microphone stream, visualizes audio frequencies, and exports standardized WAV format to meetings/meeting.wav.

02

Module 2: Speech to Text

Invokes speech_to_text.py using OpenAI Whisper neural net to transcribe audio into text saved in meetings/transcript.txt.

03

Module 3: Meeting Summarization

Invokes summarizer.py to condense transcripts into executive summaries stored in meetings/summary.txt.

04

Module 4: PDF Report Generation

Invokes report_generator.py using ReportLab to build structured PDF reports saved in meetings/Meeting_Report.pdf.
